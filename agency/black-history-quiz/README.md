# Black History Month Quiz Game

An interactive web-based quiz game to test your knowledge of Black history!

## Features

✅ **Three Difficulty Levels**: Easy, Medium, and Hard
✅ **Score Tracking**: Earn points based on difficulty and speed
✅ **Timed Questions**: 30 seconds per question with visual countdown
✅ **Educational Facts**: Learn something new after each answer
✅ **Beautiful UI**: Clean, modern interface with smooth animations
✅ **Detailed Results**: See your accuracy, correct/incorrect answers, and final score

## How to Play

1. Open `index.html` in any web browser
2. Choose your difficulty level (Easy, Medium, or Hard)
3. Read each question and select your answer before time runs out
4. Learn from the educational fact displayed after each question
5. Review your results at the end and try again!

## Scoring System

- **Easy Questions**: 10 points + time bonus
- **Medium Questions**: 20 points + time bonus
- **Hard Questions**: 30 points + time bonus
- **Time Bonus**: Extra points for faster answers (up to 6 bonus points)

## To Run

Simply double-click `index.html` or open it with your preferred web browser. No installation or server required!

## Technologies Used

- HTML5
- CSS3 (with animations and responsive design)
- Vanilla JavaScript (no dependencies)
